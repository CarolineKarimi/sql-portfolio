# Case Study #1: Danny's Diner

Original case study: https://8weeksqlchallenge.com/case-study-1/ (8 Week SQL Challenge by Danny Ma)

**Summary:** Danny's restaurant sells sushi, curry and ramen. Using three tables (`sales`, `menu`, `members`), answer questions about customer visits, spending and the loyalty program.

**Files**
- `schema.sql`: creates and fills the tables (SQLite)
- `dannys_diner.ipynb`: my queries, outputs and notes

**Tools:** SQL (SQLite), Python, pandas, Jupyter

The questions and dataset belong to the original author. The queries and notes are my own.
