# SQL Portfolio

My SQL learning notes, tutorials and case studies. I am working toward analyst roles, and I use this repo to practise on real-looking datasets and keep a reference of the patterns I learn.

## What's here

| Folder | What it is |
|---|---|
| [`cheat-sheet/`](cheat-sheet/sql_cheat_sheet.md) | My SQL reference: tricks, patterns and syntax, from `SELECT` through joins, dates, `CASE`, subqueries and CTEs |
| [`tutorials/jupyter-sql-basics/`](tutorials/jupyter-sql-basics/) | A first tutorial: running SQL inside a Jupyter notebook with SQLAlchemy |
| [`8-week-sql-challenge/`](8-week-sql-challenge/) | Case studies from Danny Ma's 8 Week SQL Challenge, with my own queries and notes |
